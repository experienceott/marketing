# OTT Studio — Foundation branch

This branch is reserved for the new OTT Marketing OS. The existing marketing website on `main` remains unchanged.

The initial application bundle has been generated separately for review. It includes:
- Editorial, image-led responsive workspace
- Campaigns, content calendar, Creator House, talent, partners, assets, ticket reporting
- Linked records, drag-and-drop scheduling and local persistence
- Supabase schema and optional team sign-in
- Honest connection status for Instagram, TikTok, YouTube and SweatPals

**Not yet production-ready:** Supabase project configuration, deployment, verified Dropbox media imports and platform OAuth are pending. No social analytics are simulated. Do not store API secrets in this repository.

GitHub Pages is not suitable for hosting a commercial team SaaS app. Choose a permitted frontend host before deployment.
